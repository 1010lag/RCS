Ты — senior product manager, mobile UX/UI designer, web designer и full-stack developer.
Нужно спроектировать и описать мобильное + веб-приложение для рабочего графика бариста одной кофейни под названием RCS.

ГЛАВНАЯ ЗАДАЧА:
Создать систему RCS для управления графиком смен бариста.
Бариста используют приложение на телефоне.
Админ использует веб-интерфейс для полного управления графиком, сотрудниками, сменами, ставками, биржей и отчётами.
Бариста не должны иметь возможность управлять общим графиком, создавать, редактировать или удалять смены других сотрудников, менять ставки, управлять сотрудниками или заходить в админскую часть.
Все изменения должны мгновенно или почти мгновенно обновляться у всех пользователей.

НАЗВАНИЕ ПРИЛОЖЕНИЯ:
RCS

ТИП ПРОДУКТА:
1. Мобильное приложение или мобильный PWA для бариста.
2. Веб-интерфейс для админа.
3. Единая база данных и общая синхронизация между мобильной и веб-частями.

ПЛАТФОРМА:
- Бариста: телефон, mobile-first, удобный интерфейс для использования одной рукой.
- Админ: веб-интерфейс, desktop-first, но адаптивный под планшет/телефон при необходимости.

ЯЗЫК:
Русский.

ВАЛЮТА:
Белорусские рубли.
Формат: BYN или Br.
Пример: 85,00 Br.
Все денежные расчёты округлять до 2 знаков после запятой.

ВРЕМЕННАЯ ЗОНА:
Europe/Minsk. UTC+3.
Все даты, время, дедлайны, напоминания, push-уведомления и расчёты должны выполняться строго по минскому времени.
Локальное время телефона нельзя использовать как источник истины.
Серверное время и часовой пояс Europe/Minsk обязательны.

КАЛЕНДАРЬ:
Приложение должно быть привязано к реальному календарю:
- текущий день;
- текущая неделя;
- текущий месяц;
- дни недели;
- даты смен;
- переходы между месяцами;
- корректная работа с реальными датами.

Неделя начинается с понедельника.
Формат даты: ДД.ММ.ГГГГ.
Формат времени: ЧЧ:ММ.

ОДНА КОФЕЙНЯ:
В системе используется одна кофейня.
Мультилокационность не нужна.
Поле location можно не использовать либо сделать одну фиксированную точку.

БЕЗ НОЧНЫХ СМЕН:
Ночные смены не поддерживаются.
Все смены должны находиться внутри одного календарного дня по Минску.
Правило:
start_datetime < end_datetime
и
дата начала = дата окончания.

Если админ пытается создать смену, переходящую через полночь, система должна отклонить это действие с понятной ошибкой.

ЦВЕТОВАЯ СХЕМА:
Приложение RCS должно быть выполнено в красно-бело-чёрных тонах.

Основная палитра:
- красный акцент: #E10600 или близкий насыщенный красный;
- белый фон: #FFFFFF;
- чёрный / тёмно-графитовый: #111111, #1A1A1A;
- светло-серый фон карточек: #F6F6F6;
- серый вспомогательный: #777777, #CCCCCC.

Стиль:
минимализм, крупные кнопки, высокая читаемость, хороший контраст, понятные статусы, удобство для быстрой работы.
Красный использовать для главных действий, активных вкладок, открытых смен на бирже, срочных уведомлений и важных статусов.
Не перегружать интерфейс.

РОЛИ ПОЛЬЗОВАТЕЛЕЙ:

1. АДМИН
Админ работает через веб-интерфейс RCS.
Админ имеет полный доступ:
- добавление, редактирование и удаление сотрудников;
- создание, редактирование и удаление смен;
- назначение бариста на смены;
- настройка типов смен;
- настройка ставок оплаты;
- просмотр общего графика;
- просмотр часов всех сотрудников;
- просмотр зарплаты всех сотрудников;
- управление биржей смен;
- откат или принудительное изменение обмена;
- просмотр журнала действий;
- отправка push-уведомлений;
- ручные корректировки часов и зарплаты с обязательной причиной;
- включение/отключение биржи для конкретных типов смен;
- блокировка конкретных смен от обмена.

Бариста не должны иметь доступ к админским функциям.
Ограничения должны быть не только в интерфейсе, но и на сервере.
Даже если бариста попытается вызвать админский API-метод, система должна отказать.

2. БАРИСТА
Бариста работает через мобильное приложение или мобильный PWA RCS.
Бариста имеет ограниченный доступ:
- видит общий график;
- видит свои смены;
- видит количество своих отработанных часов;
- видит расчёт своей зарплаты за день, неделю и месяц;
- может выставить свою смену на биржу;
- может сам забрать открытую смену с биржи без подтверждения админа;
- получает push-уведомления;
- может настроить уведомления;
- не может редактировать чужие смены;
- не может создавать, изменять или удалять смены напрямую;
- не может менять ставки;
- не может управлять сотрудниками;
- не имеет доступа к веб-админке;
- не видит зарплату других бариста.

ГЛАВНЫЕ ФУНКЦИИ RCS:

1. ГРАФИК РАБОТЫ
График должен быть виден всем авторизованным сотрудникам.

Нужны виды:
- день;
- неделя;
- месяц.

Для каждой смены в общем графике отображать:
- дату;
- время начала;
- время окончания;
- тип смены;
- имя бариста;
- статус смены.

Статусы смен:
- запланирована;
- подтверждена;
- открыта на бирже;
- занята;
- обменена;
- отменена;
- отработана;
- закрыта.

Приватность:
- общий график виден всем;
- количество часов и зарплата видны только самому бариста и админу;
- другие бариста не видят финансовую информацию друг друга.

2. НАСТРОЙКА СМЕН
Смены бывают разные, поэтому админ должен иметь возможность настраивать типы смен.

Примеры типов смен:
- открытие;
- закрытие;
- полная смена;
- короткая смена;
- подмена;
- обучение;
- праздничная смена.

Для каждого типа смены админ может задать:
- название;
- стандартное время начала;
- стандартное время окончания;
- стандартную длительность;
- тип оплаты: почасовая или фиксированная за смену;
- ставку в BYN;
- можно ли отдавать такой тип смены на биржу;
- активен ли тип смены;
- цвет или метку в рамках красно-бело-чёрной палитры.

При создании конкретной смены админ может изменить значения по умолчанию:
- время;
- сотрудника;
- тип смены;
- ставку;
- комментарий.

3. ПОДСЧЁТ ЧАСОВ РАБОТЫ
Система должна считать рабочие часы для каждого сотрудника.

ВАЖНО:
Без учёта обеда.
Перерывы не вычитаются.

Формула:
часы = время окончания - время начала.

Примеры:
с 09:00 до 18:00 = 9 часов.
с 10:00 до 16:00 = 6 часов.
с 08:30 до 17:15 = 8,75 часа.

Нужен подсчёт:
- за смену;
- за день;
- за неделю;
- за месяц;
- по конкретному бариста;
- по всей команде для админа.

Админ может вручную скорректировать часы, но обязательно с причиной и записью в журнал действий.

4. ПОДСЧЁТ ЗАРПЛАТЫ ЗА ДЕНЬ
Система должна считать зарплату за день в белорусских рублях.

Валюта:
BYN / Br.

Модели оплаты:
- почасовая ставка;
- фиксированная ставка за смену;
- индивидуальная ставка для сотрудника;
- ставка по типу смены.

Формулы:
Если оплата почасовая:
зарплата за смену = часы * ставка в BYN.

Если оплата фиксированная за смену:
зарплата за смену = фиксированная ставка.

Зарплата за день = сумма всех смен бариста за этот день.

Пример:
Бариста отработал смену с 09:00 до 18:00.
Часы = 9.
Ставка = 12 Br/час.
Зарплата за день = 108,00 Br.

Приватность зарплаты:
- каждый бариста видит только свою зарплату;
- админ видит зарплату всех сотрудников;
- другие бариста не видят чужую зарплату.

БЕЗ ТК:
Приложение не должно создавать официальные кадровые документы, трудовые договоры, табели по Трудовому кодексу, юридически значимые расчёты, бухгалтерские отчёты или документы для налоговой.
RCS — это внутренний вспомогательный инструмент для удобства команды и админа.
Все расчёты носят информационный характер.

5. БИРЖА СМЕН
Нужен раздел «Биржа смен».

Логика биржи:
- бариста может выставить свою смену на биржу;
- другие бариста видят эту смену в открытом списке;
- если кто-то хочет, он может сам забрать смену;
- подтверждение админа для забора смены не требуется;
- после того как смену забрали, ответственный автоматически меняется на нового бариста;
- старый бариста теряет эту смену;
- новый бариста получает эту смену в свой график;
- все участники получают уведомления;
- изменения сразу отражаются у всех в реальном времени.

ЖЁСТКОЕ ПРАВИЛО ПО ВРЕМЕНИ:
Смену можно выставить или забрать только до 19:00 по минскому времени в день этой смены.

То есть:
exchange_deadline = 19:00 Europe/Minsk в календарную дату смены.

Дополнительно:
- нельзя выставить смену после 19:00 её дня;
- нельзя забрать смену после 19:00 её дня;
- нельзя забрать смену, которая уже началась;
- нельзя обменивать прошедшие смены;
- после 19:00 биржа по этой смене автоматически блокируется.

Дополнительные правила биржи:
- нельзя выставить смену, которая уже была обменена;
- нельзя выставить смену, заблокированную админом;
- нельзя выставить смену, если тип смены запрещён для биржи;
- нельзя забрать свою же выставленную смену;
- нельзя забрать смену, которую уже забрали;
- нельзя забрать смену, если она пересекается с другой сменой этого же сотрудника;
- нельзя создать пересечение смен у одного бариста;
- все действия пишутся в журнал действий.

Конфликт одновременного забора:
Если два бариста одновременно нажимают «забрать смену», сервер должен обработать запрос атомарно.
Побеждает первый успешный запрос.
Второй пользователь получает сообщение: «Эту смену уже забрали».

Роль админа в бирже:
- админ видит все обмены;
- админ может откатить обмен с причиной;
- админ может вручную переназначить смену;
- админ может заблокировать конкретную смену от обмена;
- админ получает уведомления о новых обменах.

6. УДОБСТВО ДЛЯ БАРИСТА
Интерфейс бариста должен быть максимально простым.

Бариста должен за пару секунд понимать:
- когда его следующая смена;
- во сколько начинать;
- до скольки работать;
- какой тип смены;
- сколько часов;
- сколько заработает за день;
- есть ли открытые смены на бирже;
- может ли он отдать свою смену;
- какие пришли уведомления.

Главные карточки для бариста:
- «Сегодня»;
- «Завтра»;
- «Следующая смена»;
- «Мои часы»;
- «Заработано сегодня»;
- «Биржа смен»;
- «Уведомления».

7. УДОБСТВО ДЛЯ АДМИНА
Админ должен быстро:
- ставить сотрудников в график;
- видеть, кто занят;
- видеть пустые смены;
- создавать разные типы смен;
- менять ставки;
- контролировать биржу;
- видеть часы и зарплату;
- отменять ошибки;
- смотреть журнал действий;
- отправлять уведомления.

Нужны быстрые действия в веб-админке:
- копировать смену;
- повторить расписание на неделю;
- массово назначить сотрудников;
- открыть смену на биржу;
- закрыть смену;
- изменить ставку;
- добавить сотрудника;
- удалить сотрудника;
- отправить push-уведомление.

8. PUSH-УВЕДОМЛЕНИЯ
Нужны push-уведомления.

Для бариста на телефоне:
- тебе поставили смену;
- твоя смена изменена;
- твоя смена отменена;
- напоминание за 2 часа до смены;
- напоминание за 1 час до смены;
- твоя смена выставлена на биржу;
- твою смену забрали;
- ты забрал смену;
- появилась новая открытая смена на бирже;
- приближается дедлайн 19:00 для передачи смены;
- админ откатил обмен;
- админ внес ручную корректировку по часам или зарплате.

Для админа:
- бариста выставил смену на биржу;
- бариста забрал смену;
- произошёл обмен;
- смена осталась непокрытой;
- была ручная корректировка;
- изменён тип смены или ставка;
- добавлен или удалён сотрудник.

Требования к уведомлениям:
- использовать Firebase Cloud Messaging или аналог;
- deep link: тап по уведомлению открывает конкретную смену, биржу или профиль;
- пользователь может включать/выключать отдельные типы уведомлений;
- сервер хранит историю уведомлений;
- в приложении есть центр уведомлений.

9. РАБОТА И ОБНОВЛЕНИЕ У ВСЕХ
Приложение должно работать так, чтобы изменения сразу или почти сразу отображались у всех пользователей.

Требования:
- realtime-обновления через WebSocket, Supabase Realtime, Firebase Realtime, Appwrite или аналог;
- если админ поставил смену, все бариста видят обновление без ручного перезапуска;
- если один бариста забрал смену с биржи, смена исчезает у остальных и появляется в графике нового сотрудника;
- при отсутствии интернета приложение должно показывать кэшированные данные;
- после восстановления соединения данные синхронизируются с сервером;
- сервер всегда является источником истины;
- клиентское время не должно использоваться для бизнес-логики.

13. БИЗНЕС-ПРАВИЛА
- Приложение называется RCS.
- Одна кофейня.
- Бариста используют телефон.
- Админ использует веб-интерфейс.
- Дизайн красно-бело-чёрный.
- Валюта — белорусские рубли.
- Время и календарь — Europe/Minsk.
- Неделя начинается с понедельника.
- Ночные смены запрещены.
- Обед не вычитается.
- Часы = окончание - начало.
- Зарплата считается за день.
- Зарплату видит только сам бариста и админ.
- График виден всем.
- Бариста не могут управлять графиком напрямую.
- Бариста могут только выставить свою смену на биржу и забрать чужую открытую смену.
- Смену можно отдать или забрать только до 19:00 по Минску в день смены.
- После 19:00 биржа блокируется.
- Нельзя забрать смену, которая уже началась.
- Нельзя создать пересечение смен у одного сотрудника.
- Если смену забрали, она автоматически переназначается.
- Подтверждение админа для забора смены не требуется.
- Админ может откатить обмен с причиной.
- Все изменения должны обновляться у всех в realtime.
- Нужны push-уведомления.
- Нужна настройка разных типов смен.
- Без ТК, трудовых договоров и официального кадрового документооборота.
