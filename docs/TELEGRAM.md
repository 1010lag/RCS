# Telegram

RCS открывается внутри Telegram через кнопку меню бота. Бот отправляет личные уведомления о назначении и изменении смен, бирже, начислениях и напоминаниях. Получатели и категории совпадают с настройками профиля. Firebase для Telegram не нужен.

## Подключение сервера

1. Создайте бота через [@BotFather](https://t.me/BotFather), командой `/newbot`. Текущий бот команды — [@rcs_coffee_1010lag_bot](https://t.me/rcs_coffee_1010lag_bot).
2. На сервере задайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` (без `@`), `TELEGRAM_WEBHOOK_SECRET` (32–256 букв, цифр, `_`, `-`) и существующий публичный HTTPS `APP_ORIGIN`. Для секрета можно использовать `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Храните значения в секретных переменных хостинга и локальном `.env`, исключённом из Git.
3. Обновите приложение. Новые таблицы создаются при запуске. PostgreSQL, настройки push и существующие профили сохраняются.
4. С теми же секретами выполните `npm run telegram:setup -- --origin https://ваш-сервер`. Команда проверяет бота, добавляет описание, команды, кнопку «Открыть RCS», проверяет сервер и регистрирует webhook `/api/telegram/webhook`. Ошибка проверки сервера оставляет webhook без изменений. Для Render переменные задаются в Environment существующего сервиса.

## Подключение сотрудника

1. Войдите в RCS по своему телефону и паролю. Временный пароль сначала нужно сменить.
2. Профиль → Telegram → «Подключить Telegram» → «Открыть бота и подключить».
3. Нажмите «Запустить» в Telegram. Персональная ссылка действует 10 минут и используется один раз. Её нельзя передавать другим людям.
4. Бот подтвердит привязку. Откройте RCS через его кнопку. После привязки приложение поддерживает вход по подписанным данным Telegram; первый вход требует обычного профиля RCS.
5. Кнопка «Проверить Telegram» в профиле добавляет проверочное сообщение в очередь.

Для отключения используйте кнопку в профиле или `/stop` у бота. Отключение удаляет очередь данного подключения и созданные через него сессии. При смене/сбросе пароля, смене телефона администратором или отключении сотрудника привязка отзывается: потребуется повторное подключение.

## Ярлык на главном экране телефона

Откройте RCS внутри Telegram, затем в боковом меню нажмите «На главный экран». Та же кнопка есть в профиле, в разделе «Ярлык на рабочем столе». Подтвердите добавление в системном окне — ярлык будет открывать RCS в Telegram.

Используется штатный [API Telegram Mini Apps](https://core.telegram.org/bots/webapps#initializing-mini-apps): `addToHomeScreen`, `checkHomeScreenStatus` и событие `homeScreenAdded` (Bot API 8.0+). При известном статусе установленного ярлыка кнопка показывает «Ярлык добавлен». Если устройство не умеет определять статус, добавление остаётся доступным; приложение не сообщает об успехе без подтверждения Telegram. При отмене диалога можно повторить попытку. На старых клиентах или неподдерживаемых устройствах профиль показывает подсказку, а пункт бокового меню скрыт. Если системный диалог не появился, проверьте разрешение Telegram на создание ярлыков в настройках телефона.

## Доставка и ограничения

Уведомления попадают в отдельную сохраняемую очередь в одной транзакции с событием. Worker повторяет временные ошибки с задержкой, учитывает `retry_after`, прекращает отправку при блокировке бота, проверяет актуальность напоминаний. Переподключение не отправляет сообщения прежнего подключения. Повтор одного webhook-update не применяет привязку второй раз. Telegram не предоставляет ключ идемпотентности для `sendMessage`: при сетевом сбое после приёма сообщения возможен повтор.

Для входа сервер проверяет HMAC `initData`, срок 10 минут и активность привязанного профиля. Приложение нельзя встроить в произвольный сайт: разрешены только собственный origin и домены Telegram. В production при настроенном Telegram cookie использует `Secure; SameSite=None` для Telegram Web; сервер сохраняет проверки Origin и CSRF. В браузере, полностью блокирующем сторонние cookie, используйте приложение Telegram на телефоне или откройте RCS отдельно.

Worker требует работающего сервера. Пока Render Free спит или перезапускается, уведомления задерживаются. Настроенная периодическая проверка сервера снижает вероятность сна, но не гарантирует доставку в точную минуту.

Протоколы: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [Telegram Bot API](https://core.telegram.org/bots/api).
